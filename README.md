# Vehicle Valuation and Depreciation Intelligence Platform

A machine-learning platform for estimating used-vehicle listing prices and, in later versions, modelling vehicle depreciation and future value.

## Version 1 Scope

The initial model will:

- use used-car listing data;
- perform exploratory data analysis;
- preprocess selected vehicle features;
- train a multiple linear regression baseline;
- estimate a vehicle's expected listing price.
